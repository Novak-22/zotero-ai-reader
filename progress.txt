## Phase 4: AI TOC 导航 Debug (2026-05-15)

### 已修复
- [x] **页码错误 (145000 bug)**
  - 原因：parseParagraphs 正则 `/^(?:Page:\s*)?(\d+)$/` 匹配任意独立数字行（如 PDF 中的 "145000"）作为页码标记
  - 修复：添加约束 `candidate >= 1 && candidate <= 9999 && candidate >= pageNumber`，只接受合理且单调递增的页码

- [x] **无页码标记时所有条目指向同一页**
  - 原因：当 PDF 文本无真实页码标记时，所有段落 page=1，导致所有 TOC 条目都跳到第 1 页
  - 修复：检测 `distinctPages > 1` 判断是否有真实页码标记；若无则按 `paragraphIndex / totalParagraphs * readerTotalPages` 比例估算页码

- [x] **`<html:button>` 被 Zotero 安全过滤器删除**
  - 原因：renderTOCPanel 通过 innerHTML 注入 `<html:button>`，Zotero XUL 沙箱安全策略会删除 button 元素
  - 修复：删除冗余的内联刷新按钮（sectionButtons 已提供刷新功能），所有 innerHTML 统一使用 `html:` 命名空间前缀

### 验证结果
- 点击 TOC 条目后 PDF 成功跳转到对应页面（page 3→5→6→10 均验证通过）
- 无 "Removing unsafe node" / "Flattening unsafe node" 控制台错误
- 28 个 TOC 条目，页码范围合理（1-10，对应 15 页 PDF）

## 导航实现说明 (2026-05-08)

### 发现过程
1. Zotero.Reader._readers 包含所有打开的阅读器
2. ReaderTab._internalReader 包含实际阅读器实现
3. _internalReader._primaryView 是 pdf_view_PDFView 类型
4. PDFView.navigate({ pageIndex }) 方法接受 0-indexed 页码

### 实现代码
```typescript
async function navigateToPDFPage(page: number): Promise<void> {
  if (!Number.isFinite(page) || page < 1) return;

  const readers = Zotero.Reader._readers;
  if (!readers || readers.length === 0) return;

  const reader = readers[0];
  const primaryView = reader._internalReader?._primaryView;
  if (!primaryView) return;

  const totalPages = reader._internalReader._state.pageLabels?.length || 1;
  const validPage = Math.min(page, totalPages);

  // Use pdfViewer._setCurrentPageNumber directly - this is the reliable method
  const iframeWindow = (primaryView as any)._iframeWindow;
  const pdfViewer = iframeWindow?.PDFViewerApplication?.pdfViewer;

  if (pdfViewer && typeof pdfViewer._setCurrentPageNumber === "function") {
    pdfViewer._setCurrentPageNumber(validPage, true);
    return;
  }

  // Fallback to navigate method
  const navigateFn = (primaryView as any).navigate;
  if (typeof navigateFn === "function") {
    await navigateFn.call(primaryView, { pageIndex: validPage - 1 });
  }
}
```

### 关键技术发现
- `primaryView._iframeWindow.PDFViewerApplication.pdfViewer` 包含 PDF 查看器
- `pdfViewer._setCurrentPageNumber(pageNum, true)` 直接设置当前页码（1-indexed）
- `pdfViewer.currentPageNumber` 返回当前页码（1-indexed）
- `primaryView.navigate()` 方法存在异步问题，不可靠
